# SVFXT-Simple-Visual-Effects-Toon---Simple-Toon-VFX-for-Blender
A handy add-on for Blender that lets you add Toon/Anime-style visual effects (VFX) with just one click. No more wasting time composing shader nodes or building objects from scratch. Perfect for speeding up your workflow when creating stylized animations or crafting visual assets ready for export to a game engine.
